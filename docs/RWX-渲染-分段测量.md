# 渲染分段测量（units 拆细）

`RWX_PROF_RENDER` 里的 `units` 一段原来是 5 个遍历混在一起，看不出贵在哪。
现在拆成四段：

| 字段 | 含义 |
| --- | --- |
| `u_sdraw` | 需要重绘的单位 `d()` 遍历 |
| `u_edraw` | 主绘制 `e()` 遍历 |
| `u_layer` | 分层绘制 `c()` 遍历（drawLayer 非 0/10） |
| `u_adraw` | 附加层 `a()` 遍历 |

## 实测（同一台机器，窗口模式，自动刷兵）

| 单位数 | draw | u_layer | u_sdraw | u_adraw | map |
| --- | --- | --- | --- | --- | --- |
| 600 | 2.46 ms | 1.14 ms | 0.12 ms | 0.39 ms | 0.69 ms |
| 1500 | 2.19–4.07 ms | 1.33–2.99 ms | 0.24–0.29 ms | 0.15–0.29 ms | 0.14–0.19 ms |

## 结论

1. **瓶颈是 `u_layer`（分层绘制遍历）**：单位越多它涨得越快，1500 单位时 2.99 ms，
   占 units 段的绝对大头；`u_sdraw` / `u_adraw` 都在 0.3 ms 以下。
2. `gap` 稳定在 8.3 ms 左右（帧间隔里的等锁/等待），不是绘制本身。
3. 下一步就对着 `u_layer` 那个循环改：先看 `c(float)` 里到底做了什么、
   能否按图集/材质批处理，或在缩放很小时跳过其中不必要的层。
