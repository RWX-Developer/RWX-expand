# 寻路实验台（完全隔离）

不启动游戏，直接喂真实代价网格，跑**游戏里那份** `RwxAStar.java`（原样拷入，不改）。
目录：`tools/pathlab/`

## 怎么跑

```bash
# 批量：300 组随机起终点，出统计
bash tools/pathlab/run.sh

# 单例：起点 40,180 -> 终点 200,60
bash tools/pathlab/run.sh 40 180 200 60
```

输出：`tools/pathlab/out/worst.ppm`（最差偏离案例）、`out/path.ppm`（单例）。
灰度 = 可走格，深色 = 不可走，红 = 路径，绿 = 起点，蓝 = 终点。

## 数据

`data/cost-LAND.csv`：从运行中的游戏导出的陆军代价图，Crossing Large (10p)，230×230。
-2 = 不可走，其余 = 该格代价。来源 `docs/images/rwx-grid-cost-LAND.csv`。

## 首次实测（2026-11-23）

```
cases=300 ok=226 fail_unreachable=63 fail_astar=11
avgNodes=111 borderHitsTotal=56 pairsEndNearBorder=34
worstDeviation=72.5 case=183,208 -> 205,38
```

结论：
1. **A* 不贴边界**。226 条成功路径里共 56 个贴边航点，全部来自「起终点本身就在边界附近」的 34 组。
   内点之间的路径贴边数为 0。
2. **11/300 在可达情况下 A* 放弃**（MAX_EXPAND=6000 太小），这是真 bug。
3. **最差偏离 72.5 格是地形导致的合理绕行**（两端被大片水域隔开），不是算法走歪。
   → 说明「偏离起点-终点连线超过 3 格就删航点」这条规则会误删正确路径点。
4. 平均 111 个航点 = 逐格一个点，和引擎原路径一致。

## 边界

- 只测了陆军（LAND）代价图，海军/悬浮/飞行没测。
- 代价全部为 0（这张图没有代价>0 的地形），所以 COST_SCALE 加权效果测不出来。
- 实验台不含 `PathSolver.e()/g()` 的扫描逻辑，只测 A* 本体。
