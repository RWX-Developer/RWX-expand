# 同局 A/B：u_layer 的「跳过空实现」实验

跨轮比较不可用（每轮兵数不同、场景在变），所以把 A/B 做进同一局：
每 600 帧切一次模式，`RWX_PROF_RENDER` 每 600 帧输出一行，正好一行一个模式。

```
umode=A_base  objs=2403 draw=12.08 u_layer=6.41   → 2.67 µs/对象
umode=B_skip  objs=2513 draw=12.28 u_layer=6.64   → 2.64 µs/对象
```

11 对样本，**没有收益**（差 1%，在噪声内）。

## 为什么没收益

1. 跳过的是「`c(float)` 继承自 `BaseUnit` 空实现」的对象；台架的兵是 JVM 模组单位，
   模组生成的类型自己声明了 `c(float)`，本来就跳不掉。
2. 剩下能跳的只是少数静态对象，省不出东西。
3. 2.6 µs/对象这个量级说明成本在**遍历与访问**本身，不在那次调用。

## 结论

这刀不成立，默认关闭（`rwxABSkipNoop = false`），没有部署收益。
采样本身保留：渲染行现在带 `objs=`（本帧绘制对象数）和 `umode=`，
以后任何改法都能用同一局 A/B 直接对比，不用再受跨轮噪声干扰。
